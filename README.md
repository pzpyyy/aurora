# Aurora

#### 介绍
多功能清理模块
本模块追求极低开销实现清理
和其他方案对比。定时方案
1. 传统 Cron 方案
工作机制：每分钟唤醒一次，检查任务表并执行到期任务

2. While + Sleep 轮询方案
工作机制：每秒循环检查，通过 sleep 实现间隔

3. 本方案（单TimerFD + Epoll）
工作机制：基于事件驱动，精确按任务时间唤醒

场景测试：10个凌晨任务
📊 24小时功耗数据对比
指标	Cron方案	While+Sleep	本方案
总唤醒次数  1,450次	86,400次	10次
无效唤醒率  99.3%	99.99%	         0%
CPU占用	中高(1-3%)	高(3-5%)	极低(<0.1%)
电池影响	明显(1-3%)	严重(5-10%)	可忽略(<0.1%)
